# 행정동 위험유형 자동 분류

> 담당: 엄세용 · 산출 파일: `risk_type_rules.csv`, `risk_type_master.csv`

---

## 1. 기능 개요

본 기능은 행정동별 DLFI 총점만 보여주는 방식에서 벗어나, **어떤 위험요인이 해당 지역의 생활물류 마찰을 주도하는지 자동으로 분류**합니다.

같은 고위험 지역이라도 배송수요, 보행충돌, 반복단속, 안전취약, 하역공간 부족 등 원인이 다르기 때문에 동일한 정책을 적용하면 효과가 낮을 수 있습니다. 따라서 82개 행정동의 6개 세부지표를 동일한 백분위 기준으로 비교해 주위험유형과 보조위험유형을 산출하고, 유형에 맞는 관리 방향을 함께 제공합니다.

```
행정동별 6개 DLFI 세부지표
        ↓
위험방향 통일 및 행정동 백분위 변환
        ↓
주위험유형·보조위험유형 자동 지정
        ↓
기존 K-Means 군집 결과와 교차 확인
        ↓
유형별 정책 관리 방향 제공
```

## 2. 산출 방법

### 2-1. 입력 데이터

기준 입력 파일은 `final_modelling.csv`이며 대전시 82개 행정동을 대상으로 다음 지표를 사용했습니다.

| 지표 | 원본 컬럼 | 위험방향 |
| --- | --- | --- |
| 배송수요 | 배송수요점수_최종 | 높을수록 위험 |
| 교통방해 | 교통방해점수 | 높을수록 위험 |
| 보행충돌 | 보행충돌점수_최종 | 높을수록 위험 |
| 단속반복 | 단속반복점수 | 높을수록 위험 |
| 안전취약 | 안전취약점수 | 높을수록 위험 |
| 하역부족 | 하역여유점수 | 낮을수록 위험 |

### 2-2. 백분위 변환

원점수는 지표마다 분포와 범위가 다르므로 그대로 비교하지 않았습니다. 각 지표를 82개 행정동 내 위험 백분위로 변환했습니다.

```
일반 위험지표 = 해당 값보다 낮은 행정동의 비율
하역부족지표 = 해당 값보다 하역여유가 높은 행정동의 비율
```

특히 하역여유점수는 대부분 0~16점에 집중돼 있어 단순히 `100-원점수`를 적용하면 거의 모든 행정동이 하역부족형으로 분류되는 문제가 있습니다. 이를 방지하기 위해 **순위 기반 백분위**를 사용했습니다.

### 2-3. 위험유형 지정

6개 위험 백분위 중 가장 높은 지표를 주위험유형, 두 번째 지표를 보조위험유형으로 지정했습니다.

| 위험유형 | 핵심 판단지표 | 기본 관리 방향 |
| --- | --- | --- |
| 공동주택 배송집중형 | 배송수요 | 배송시간 분산·공동배송 운영 검토 |
| 상권·교통 혼잡형 | 교통방해 | 혼잡시간대 하역 회피·탄력 운영 |
| 역세권 보행충돌형 | 보행충돌 | 출퇴근·보행 피크시간 하역 제한 |
| 단속반복형 | 단속반복 | 탄력 하역권·단속 운영기준 검토 |
| 안전취약형 | 안전취약 | 등하교·취약계층 이동시간 회피 |
| 하역공간 부족형 | 하역부족 | 임시 하역면·마이크로 거점 우선 검토 |

### 2-4. 분류명확도

분류명확도는 주위험 백분위와 보조위험 백분위의 차이로 계산했습니다.

```
분류명확도 = 50 + (주위험백분위 - 보조위험백분위) × 0.5
상한값 = 95
```

이 값은 통계적 예측확률이 아니라 **두 위험요인 중 어느 요인이 상대적으로 더 뚜렷한지를 보여주는 설명용 지표**입니다.

### 2-5. 기존 군집과의 관계

기존 K-Means 군집과 군집유형은 제거하지 않고 보조 설명으로 유지했습니다. K-Means는 비슷한 지표 구조를 가진 지역군을 찾는 역할을 하고, 본 기능은 각 행정동에 정책 대응이 가능한 세부 위험 라벨을 부여하는 역할을 합니다.

## 6. 한계사항 및 활용 주의

- 위험유형은 인과관계를 확정하는 결과가 아니라, 현재 확보한 공공데이터에서 상대적으로 두드러진 위험요인을 설명하는 분류입니다.
- 백분위는 대전 82개 행정동 내부의 상대평가이므로 다른 도시와 직접 비교할 수 없습니다.
- 교통방해점수 28.1 대체값과 하역여유점수의 낮은 변별력은 분류 결과 해석 시 함께 표시해야 합니다.
- 주위험과 보조위험 백분위 차이가 작은 지역은 단일 유형보다 복합위험 지역으로 해석해야 합니다.
- 가양1동은 기존 입력 데이터에서 이상치로 분리된 지역이므로 별도 품질 플래그와 함께 확인해야 합니다.
- 본 기능은 기존 DLFI를 수정하지 않으며, DLFI 결과를 해석하고 정책 방향을 구체화하는 설명 기능입니다.
