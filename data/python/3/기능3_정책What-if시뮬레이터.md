# 정책 What-if 시뮬레이터 및 정책 패키지 추천

> 담당: 정대교 · 산출 파일: `feature3_policy_whatif_streamlit.py`

---

## 1. 기능 개요

본 기능은 행정동별 위험요인에 정책을 적용했을 때 세부 위험점수와 DLFI가 어떻게 달라지는지를 비교하는 정책 시뮬레이션 기능입니다.

행정 담당자가 대상 행정동, 정책 우선기준, 정책 적용 강도와 적용할 정책을 선택하면 다음 결과를 제공합니다.

- 정책 적용 전·후 DLFI
- 세부 위험지표 변화
- 정책별 예상 효과
- 비용·난이도·시행기간
- 정책 우선순위
- 단계별 정책 패키지

정책 효과는 실제 실증값이 아니라 초기 MVP용 정책 규칙값이며, 향후 시범사업 데이터나 전문가 합의 결과로 보정합니다.

```text
행정동별 DLFI 및 위험유형
        ↓
대상 행정동과 정책 선택
        ↓
정책별 세부 위험점수 변화 계산
        ↓
적용 전·후 DLFI 비교
        ↓
비용·효과·실행 가능성 기반 정책 순위 산출
        ↓
단기·중기 정책 패키지 추천
```

## 2. 산출 방법

### 2-1. 입력 데이터

기준 입력 파일은 `final_modelling.csv`이며 다음 컬럼을 사용합니다.

| 구분 | 입력 컬럼 | 활용 목적 |
|---|---|---|
| 지역정보 | 행정동코드, 시군구, 행정동 | 시뮬레이션 대상 지역 선택 |
| 종합위험 | DLFI_최종점수 | 정책 적용 전 기준점수 |
| 배송수요 | 배송수요점수_최종 | 배송수요 관련 정책효과 계산 |
| 교통위험 | 교통방해점수 | 교통방해 개선효과 계산 |
| 보행위험 | 보행충돌점수_최종 | 보행충돌 개선효과 계산 |
| 단속위험 | 단속반복점수 | 반복단속 개선효과 계산 |
| 안전위험 | 안전취약점수 | 안전정책 개선효과 계산 |
| 하역공간 | 하역여유점수, 하역부족위험 | 하역공간 정책효과 계산 |

| 정책정보 | 우선순위등급, 추천정책_텍스트 | 기존 추천 결과와 비교 |

### 2-2. 정책 규칙

| 정책 | 주요 영향지표 | 비용 | 난이도 | 시행기간 |
|---|---|---|---|---|
| 탄력 하역공간 운영 | 하역여유·단속반복·교통방해 | 중간 | 중간 | 중기 |
| 배송시간 분산 | 교통방해·보행충돌·단속반복 | 낮음 | 낮음 | 단기 |
| 소형 마이크로 하역거점 | 하역여유·배송수요·교통방해 | 중간~높음 | 높음 | 중기 |
| 특정 시간대 하역 제한 | 보행충돌·안전취약·교통방해 | 낮음 | 중간 | 단기 |
| CCTV 재배치 | 단속반복 | 중간 | 중간 | 중기 |
| 상습구간 표지 강화 | 단속반복·교통방해 | 낮음 | 낮음 | 단기 |
| 보호구역 완충구간 | 보행충돌·안전취약 | 중간 | 높음 | 중기 |
| 시민·상인 사전안내 | 단속반복·교통방해·보행충돌 | 낮음 | 낮음 | 단기 |

### 2-3. 정책효과 적용

정책효과는 다음 세 가지 방식으로 반영합니다.

```text
절대 감소: 기존 위험점수에서 일정 점수 차감
비율 감소: 기존 위험점수에서 일정 비율 감소
절대 증가: 하역여유점수와 같은 긍정지표를 일정 점수 증가
```

예를 들어 탄력 하역공간 운영을 최대 강도로 적용하면 다음과 같이 계산합니다.

```text
하역여유점수 최대 25점 증가
단속반복점수 최대 15점 감소
교통방해점수 최대 10점 감소
```

정책 적용 강도를 50%로 선택하면 각 최대 효과의 50%만 적용합니다.

모든 점수는 0~100 범위로 제한합니다.

### 2-4. DLFI 변화 계산

세부 위험지표 기반 DLFI는 다음과 같이 계산합니다.

```text
세부지표 DLFI
= 배송수요
+ 교통방해
+ 보행충돌
+ 단속반복
+ 안전취약
- 하역여유
```

정책 적용 전과 적용 후 세부지표 DLFI의 차이를 개선폭으로 계산합니다.

```text
DLFI 개선폭
= 정책 적용 전 세부지표 DLFI
- 정책 적용 후 세부지표 DLFI
```

최종 화면에서는 원본 데이터의 공식 `DLFI_최종점수`를 기준으로 유지하고, 계산된 개선폭만 차감합니다.

```text
적용 후 공식 DLFI
= 기존 DLFI_최종점수
- 세부지표 개선폭
```

### 2-5. 정책 추천점수

균형형 기준은 다음 가중치를 사용합니다.

```text
종합 정책점수
= 효과점수 × 40%
+ 비용효율 × 25%
+ 실행용이성 × 20%
+ 시행속도 × 15%
```

사용자는 다음 기준 중 하나를 선택할 수 있습니다.

- 균형형
- 효과 우선
- 비용 우선
- 빠른 실행 우선

선택한 기준에 따라 정책평가 가중치가 변경됩니다.

### 2-6. 단계별 정책 패키지

행정동의 상위 위험요인 TOP 3와 정책별 종합점수를 결합해 3단계 정책 패키지를 생성합니다.

| 주요 위험요인 | 우선 연결 정책 |
|---|---|
| 하역공간 부족 | 탄력 하역공간, 마이크로 하역거점 |
| 단속반복 | 상습구간 표지 강화, CCTV 재배치 |
| 보행충돌·안전취약 | 시간대 하역 제한, 보호구역 완충구간 |
| 교통방해·배송수요 | 배송시간 분산, 시민·상인 사전안내 |

정책 패키지는 단기 정책을 먼저 배치하고, 이후 중기 정책으로 이어지도록 구성합니다.

## 3. 산출 결과

본 기능은 선택한 행정동에 대해 다음 결과를 실시간으로 산출합니다.

| 산출 결과 | 설명 |
|---|---|
| 현재 DLFI | 정책 적용 전 공식 DLFI |
| 적용 후 DLFI | 정책효과를 반영한 예상 DLFI |
| DLFI 감소폭 | 적용 전·후 점수 차이 |
| DLFI 감소율 | 기존 DLFI 대비 감소 비율 |
| 세부지표 변화 | 배송·교통·보행·단속·안전·하역부족 변화 |
| 정책별 순위 | 선택 기준에 따른 정책 우선순위 |
| 정책 패키지 | 단기·중기 3단계 실행안 |
| 결과 CSV | 선택 조건과 결과를 저장한 다운로드 파일 |

정책별 비교 결과는 다음 형태로 출력됩니다.

| 정책 | 적용 후 DLFI | DLFI 감소 | 비용 | 난이도 | 시행기간 | 종합 정책점수 |
|---|---:|---:|---|---|---|---:|
| 배송시간 분산 | 자동 계산 | 자동 계산 | 낮음 | 낮음 | 단기 | 자동 계산 |
| 탄력 하역공간 | 자동 계산 | 자동 계산 | 중간 | 중간 | 중기 | 자동 계산 |
| 마이크로 하역거점 | 자동 계산 | 자동 계산 | 중간~높음 | 높음 | 중기 | 자동 계산 |

## 4. 화면 적용 방법

### 4-1. 사용자 입력

Streamlit 사이드바에서 다음 조건을 선택합니다.

- 시군구
- 행정동
- 정책 우선기준
- 정책 적용 강도
- 적용할 정책 조합

### 4-2. 현재 위험정보

```text
현재 DLFI
위험유형
우선순위등급
주요 위험요인 TOP 3
```

### 4-3. 적용 전·후 비교

- 정책 적용 전·후 DLFI 카드
- DLFI 감소폭과 감소율
- 세부 위험지표 막대그래프
- 적용 후 DLFI 게이지
- 세부지표 변화표

### 4-4. 정책 추천

- 정책별 효과·비용·난이도·시행기간 비교
- 선택한 우선기준에 따른 정책순위
- 단기·중기 3단계 정책 패키지
- 기존 추천정책과 What-if 추천 비교

### 4-5. 결과 다운로드

선택한 정책 조건과 시뮬레이션 결과를 CSV로 다운로드할 수 있습니다.

## 5. 다른 기능과의 연결

```text
기능 2 위험유형 자동 분류
        ↓
행정동별 위험유형과 주요 위험요인 전달
        ↓
기능 3 정책 What-if 시뮬레이터
        ↓
정책별 DLFI 개선효과와 실행 우선순위 산출
        ↓
기능 1 하역공간 후보지·운영시간 추천과 연계
```

기능 3은 기능 2의 `위험유형`, `추천정책_텍스트` 결과를 사용하며, 행정동별 위험원인에 맞는 정책을 구체적으로 비교합니다.

## 6. 차별성

| 기존 방식 | 본 기능 |
|---|---|
| 위험지역 순위만 제공 | 정책 적용 후 예상 변화를 함께 제공 |
| 한 개 정책만 단순 제시 | 여러 정책 조합을 동시에 비교 |
| 정책효과만 고려 | 비용·난이도·기간을 함께 평가 |
| 모든 지역에 같은 정책 추천 | 위험요인 TOP 3 기반 맞춤 추천 |
| 단일 정책 제시 | 단기·중기 단계별 패키지 제공 |
| 분석 결과 확인으로 종료 | 결과 CSV 다운로드와 행정 검토자료 제공 |

## 7. 한계사항 및 활용 주의

- 정책 효과값은 실제 실증 결과가 아니라 초기 MVP용 규칙값입니다.
- 시범사업 결과와 전문가 자문을 통해 정책별 효과값을 보정해야 합니다.
- 계산된 적용 후 DLFI는 정책효과를 비교하기 위한 상대적 시나리오이며 실제 감소를 보장하지 않습니다.
- 복수 정책을 선택하면 정책효과가 순차 적용되며 정책 간 상호작용은 현재 별도로 모델링하지 않았습니다.
- 비용과 난이도는 절대적인 예산·기간이 아니라 정책 간 상대 비교값입니다.
- `final_modelling.csv`의 컬럼명이나 산식이 변경되면 입력 컬럼과 DLFI 계산식을 함께 수정해야 합니다.
- 이상치로 분리된 행정동은 정책 시뮬레이션 결과 해석에 주의해야 합니다.
- 실제 정책 도입 전 현장조사, 관계기관 협의와 시범운영이 필요합니다.
