# 기능4 데이터 신뢰도 레이어 — 산식 확정(v2) 반영 노트

> 기존 서식3 초안(`서식3_기능4_데이터신뢰도레이어_초안.md`)의 2-3·3-2·3-3 절을 아래 내용으로 교체.
> 산출 파일: `reliability_master_v2.csv` (재계산본), 재현 스크립트 `05_recompute_reliability.py`

## 산식 확정 배경

세 가지 안을 비교해 결합안으로 확정했다.

| 안 | 산식 | 문제/한계 |
| --- | --- | --- |
| 기획서(차별 기능.md) | 최신성20 + 매칭률25 + 완전성20 + 직접성20 + 변수일관성15 | 매칭률은 전처리 로그가 없어 데이터셋별 단독 재현 불가, 변수일관성은 행정동별 정량화 불가 |
| 기존 구현(v1) | 최신성20 + 직접성20 + 완전성35 + 근거강도25 | 근거강도(모델 확신도)가 25%로 과대 → 저위험 동이 "데이터가 좋아서"가 아니라 "모델이 확신해서" 신뢰도를 높게 받는 왜곡 |
| **확정(v2)** | **최신성20 + 직접성20 + 완전성50 + 근거강도10** | 완전성이 유일한 행정동별 데이터품질 신호이므로 지배 가중 |

확정 근거:
- **최신성·직접성 20%**는 기획서대로 유지한다(데이터셋 기반 상한, 82개 동 공통값 80.6·87.6).
- 기획서의 **매칭률(25%)**은 이미 완전성 안에 "교통수단 확보율(1~3종)"로 반영되어 있으므로 **완전성에 통합(20→50%)**한다. 완전성은 수단 확보수·대체값·결측·보정 이력을 담은 유일한 행정동별 변별 신호다.
- **근거강도**는 데이터 품질이 아니라 모델 예측 확신도이므로 25→10%로 낮춰 보조지표로만 유지한다(SHAP 공개 서사는 보존).
- 기획서의 **변수일관성(15%)**은 행정동별 정량화가 불가능하고 사실상 상수라 제외한다.

## 2-3. 신뢰도 산식 (교체)

```
데이터신뢰도 = 최신성 × 20% + 직접성 × 20% + 완전성 × 50% + 근거강도 × 10%
```

| 항목 | 가중 | 산출 근거 |
| --- | ---: | --- |
| 최신성 | 20% | 데이터셋 기준일 경과월(12개월 100/24개월 80/36개월 60/그 이상 40), 82동 공통 80.6 |
| 직접성 | 20% | 연결방식 5단계 점수의 지표별 가중평균, 82동 공통 87.6 |
| 완전성 | 50% | 교통수단 확보수(1~3종)·대체값·결측·보정 이력 (기획서 매칭률 개념 통합) |
| 근거강도 | 10% | 모델 예측 확신도 + SHAP 제공 여부(보조) |

## 3-2. 행정동 신뢰도 등급 분포 (교체)

| 등급 | v1 | **v2** |
| --- | ---: | ---: |
| 높음(≥85) | 9 | **12** |
| 보통(70~84) | 59 | **45** |
| 주의(50~69) | 14 | **25** |
| 낮음(<50) | 0 | **0** |

- 상향(→높음) 3개: 노은3동·중앙동·둔산1동 (교통데이터 3종 전부 확보, 완전성 100)
- 하향(→주의) 11개: 복수동·정림동·비래동·목동·석교동·유천2동·태평2동·부사동·목상동·홍도동·대청동 (교통데이터 1종만·VDS 전면결측, 완전성 45). v1에서는 저위험 동의 높은 모델 확신도가 신뢰도를 보통으로 끌어올렸으나, v2는 데이터 공백을 정직하게 드러낸다.

## 3-3. DLFI × 신뢰도 교차 분류 (교체)

| 구분 | 판단 | v1 | **v2** |
| --- | --- | ---: | ---: |
| ① DLFI 높음 + 신뢰도 높음 | 시범사업 우선 검토 | 17 | **17** |
| ② DLFI 높음 + 신뢰도 낮음 | 현장조사·추가데이터 우선 | 4 | **4** |
| ③ DLFI 낮음 + 신뢰도 높음 | 관찰 유지 | 51 | **40** |
| ④ DLFI 낮음 + 신뢰도 낮음 | 보완조사 대상 | 10 | **21** |

- ①·②는 불변(고DLFI 상위 21개 동 구성·판정 동일). ② 현장조사 우선 대상은 그대로 탄방동·대흥동·가양2동·오정동 4곳.
- ③→④로 11개 동 이동. 교통데이터가 1종만 확보된 저위험 동들이 "안전하다"가 아니라 "데이터 부족으로 단정 불가(보완조사)"로 재분류된다. 데이터 기반 행정의 사각지대(미측정 지역) 경고 기능이 강화된다.
