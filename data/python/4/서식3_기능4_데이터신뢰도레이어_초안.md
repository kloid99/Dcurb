> 서식3(분석과정보고서) 삽입용 초안 · 작성기준일 2026-07-22
> 산출 파일: `data_source_registry.csv`, `reliability_master.csv`

## 1. 기능 개요

본 과제의 DLFI(생활물류 마찰지수)는 실제 택배차량 운행 데이터를 직접 확보하지 못한 상태에서, 공공데이터 대리변수를 조합해 산출한 지표입니다. 따라서 **점수가 높다는 사실만큼이나 그 점수를 뒷받침하는 데이터가 얼마나 믿을 만한지가 함께 제시되어야** 정책 판단에 쓸 수 있습니다.

데이터 신뢰도 레이어는 이 문제를 다루기 위한 기능으로, 82개 행정동 각각에 대해 다음을 함께 보여줍니다.

- 어떤 데이터가 언제 만들어진 자료인지
- 그 데이터가 행정동에 어떤 방식으로 연결됐는지
- 값이 실측인지 대체값인지
- 그래서 이 지역의 분석 결과를 어느 수준까지 신뢰할 수 있는지

쉽게 말하면 **"이 지역이 위험합니다"와 "그 판단의 근거가 이만큼 튼튼합니다"를 한 화면에서 같이 보여주는 장치**입니다.

중요한 원칙은 **신뢰도가 DLFI 점수를 깎지 않는다**는 점입니다. 위험도와 데이터 품질은 성격이 다른 정보이므로 두 축을 분리해 병렬로 제시하고, 마지막에 교차시켜 정책 우선순위를 도출합니다.

## 2. 산출 방법

### 2-1. 데이터셋 메타 레지스트리

활용 데이터 56건 중 DLFI 산식에 반영된 **52건**을 대상으로 데이터셋별 기준일·제공기관·연결방식·기여지표를 구조화했습니다. (기상 1건, 이벤트 3건은 DLFI 1차 산식에서 제외되어 대상에서 뺐습니다.)

| 구분 | 건수 |
| --- | ---: |
| 전체 레지스트리 등재 | 52 |
| 기준일 확인 가능 | 44 |
| 기준일 확인 불가 | 8 |

### 2-2. 연결 방식 구분

데이터가 행정동에 어떻게 연결됐는지에 따라 5단계로 나누고 점수를 부여했습니다. 좌표로 직접 연결한 경우가 가장 신뢰도가 높고, 다른 데이터로 추정한 경우가 가장 낮습니다.

| 연결 방식 | 설명 | 직접성 점수 |
| --- | --- | ---: |
| 직접 매핑 | 좌표·행정동 코드로 직접 연결 | 100 |
| 주소 변환 | 주소를 좌표화해 연결 | 85 |
| 면적 비례 배분 | 상위 지역 데이터를 면적 비중으로 배분 | 65 |
| 인구 비례 배분 | 상위 지역 데이터를 인구 비중으로 배분 | 50 |
| 대리변수 추정 | 다른 데이터를 이용해 추정 | 35 |

### 2-3. 신뢰도 산식

```
데이터신뢰도 = 최신성 × 20%
             + 직접성 × 20%
             + 완전성 × 35%
             + 근거강도 × 25%
```

| 항목 | 산출 근거 |
| --- | --- |
| 최신성 | 데이터셋 기준일의 경과 개월수 (12개월 이내 100 / 24개월 80 / 36개월 60 / 그 이상 40) |
| 직접성 | 연결 방식 5단계 점수를 지표별로 가중평균 |
| 완전성 | 행정동별 대체값·결측·보정 이력에 따른 감점 |
| 근거강도 | 모델 예측 확신도와 SHAP 설명 근거 제공 여부 |

최신성과 직접성은 데이터셋 속성이므로 82개 행정동에 공통 적용됩니다(각 80.5점, 87.6점). **행정동 간 차이는 완전성과 근거강도에서 발생**합니다.

### 2-4. 등급 기준

| 점수 | 등급 | 활용 기준 |
| --- | --- | --- |
| 85점 이상 | 높음 | 정책 검토 우선 가능 |
| 70~84점 | 보통 | 현장 확인 후 활용 |
| 50~69점 | 주의 | 추가 데이터 확보 필요 |
| 50점 미만 | 낮음 | 정책 판단 근거로 제한 |

이 등급은 **DLFI가 맞거나 틀리다는 의미가 아니라, 분석에 사용한 데이터의 품질과 연결 수준**을 나타냅니다.

| --- | --- | ---: |
| ① DLFI 높음 + 신뢰도 높음 | 시범사업 우선 검토 | 17 |

**② 현장조사 우선 대상**: 탄방동(DLFI 17위), 대흥동(19위), 가양2동(20위), 오정동(21위)

네 곳 모두 도로혼잡도(VDS) 데이터가 결측인 행정동입니다. DLFI 상위권이지만 교통방해점수가 실측이 아니므로, 시범사업 대상 확정 전에 현장 교통량 조사가 선행되어야 합니다.

**④ 보완조사 대상 10개 동**은 "위험이 낮다"고 단정할 수 없는 지역입니다. DLFI가 낮게 나온 이유가 실제로 안전해서인지, 데이터가 부족해서인지 구분되지 않기 때문입니다.

## 4. 데이터 품질 점검 결과

본 레이어를 적용한 결과 다음 사항을 확인했습니다. 이 항목들은 분석 결과 해석 시 반드시 함께 고려되어야 합니다.

### 4-1. 교통방해점수 대체값 (32개 행정동)

교통방해점수가 **28.1로 동일한 행정동이 32개(전체의 39.0%)** 확인되었습니다. 원인을 추적한 결과, `traffic_master.csv`의 `도로데이터` 플래그가 0인 행정동이 정확히 31개이며 **이 31개 전부가 28.1**이었습니다. 즉 VDS 도로 교통량 데이터가 확보되지 않은 지역에 부여된 고정 대체값입니다.

해당 대체값 28.1은 도로데이터 보유 집단(50개 동)의 어떤 통계량과도 일치하지 않았습니다(25백분위 36.8, 중앙값 43.9, 평균 43.7). 전처리 상위 단계에서 산출된 값으로 **산출 근거를 확인하지 못했습니다.**

이 32개 동에는 DLFI 13위 은행선화동, 17위 탄방동, 19위 대흥동, 20위 가양2동 등 상위권 지역이 포함됩니다.

### 4-2. 괴정동 대체값 오적용 (확인된 오류)

32개 동 중 **괴정동 1개는 도로데이터를 보유하고 있음에도 대체값이 적용**된 것으로 확인되었습니다.

| 행정동 | 교통량 | 출퇴근혼잡도 | 교통방해점수 |
| --- | ---: | ---: | ---: |
| 중촌동 | 26,208 | 40.8 | 49.2 |
| **괴정동** | **26,212** | **42.6** | **28.1** |
| 둔산1동 | 26,314 | 57.8 | 42.6 |

교통량이 4대 차이인 중촌동이 49.2인 반면 괴정동만 28.1입니다. 도로데이터 보유 50개 동을 기준으로 회귀 추정 시 기대값은 약 40.0입니다.

**본 보고서에서는 해당 값을 수정하지 않고 원자료 상태를 유지**했습니다. 사유는 다음과 같습니다.

- 교통방해점수의 원 산식을 재현하지 못해 정확한 보정값을 확정할 수 없음
- 시나리오별 검토 결과 괴정동 순위는 39위에서 27~33위로 이동하나, 고위험 전환(임계 248.43)은 발생하지 않으며 상위 20위권 구성에도 변동이 없음

따라서 `reliability_master.csv`의 품질플래그에 `교통방해_대체값(괴정동_오적용확인)`으로 기록하고, 향후 재계산 대상으로 관리합니다.

### 4-3. 단속반복점수의 기준일 불일치

단속반복점수는 5개 자치구의 불법주정차 단속현황을 통합해 산출했으나, 자치구별 데이터 기준일이 일치하지 않습니다.

| 자치구 | 단속현황 기준일 |
| --- | --- |
| 중구 | 2023-11-30 |
| 유성구 | 2023-12-08 |
| 동구 | 2024-12-31 |
| 서구 | 2025-12-31 |
| 대덕구 | 2026-04-24 |

최대 **2년 5개월** 차이가 있어, 서로 다른 기간의 단속 실적을 동일 기준으로 비교한 구조입니다.

다만 기준일 경과월과 자치구 평균 단속반복점수의 상관계수는 **−0.040**으로, 관측 가능한 체계적 편향은 확인되지 않았습니다. 표본이 5개로 검정력이 낮으므로 단정하지 않고 한계로 기재합니다.

### 4-4. 하역여유점수의 변별력 부족

하역여유점수는 이상치인 가양1동(100.0)을 제외할 경우 **범위 0~16.19, 평균 2.37**로 분포가 매우 좁습니다. 81개 동 중 71개가 5 미만이며 9개 동은 정확히 0.0입니다.

하역공간 부족이 본 과제의 핵심 문제의식임에도, 해당 변수가 행정동 간 차이를 충분히 구분하지 못하고 있습니다. 0.0인 9개 동은 별도 파일에서도 `순위신뢰여부 = N`으로 이미 플래그되어 있어, 동일한 문제가 두 경로에서 확인되었습니다.

### 4-5. 설명 근거(SHAP)의 제공 범위

모델 예측 근거를 SHAP으로 산출한 행정동은 **82개 중 5개(상위 5개 동)**입니다. 나머지 77개 동은 규칙 기반 보조 근거로 대체되었으며, 이는 `기여변수_출처` 컬럼에 `SHAP` / `규칙기반(보조)`으로 구분되어 있습니다.

본 레이어에서는 이를 근거강도 항목에 반영해, SHAP 미제공 동의 신뢰도를 낮게 산출했습니다.

### 4-6. 시간대 검증의 공간 해상도

시간대별 하역 추천의 타당성을 사고 실측 데이터와 대조했으나, 활용한 실측값(시간당 사상자)은 **대전시 전체 단일 시계열**로 82개 행정동에 동일하게 적용됩니다.

| 시간대 | 실측 시간당 사상자 | 보행위험 순위 |
| --- | ---: | ---: |
| 07~10 | 279.0 | 1 |
| 10~12 | 336.0 | 2 |
| 12~14 | 355.5 | 3 |
| 20~23 | 405.7 | 4 |
| 14~17 | 443.7 | 5 |
| 17~20 | 560.0 | 6 |

따라서 이 검증은 **행정동별 검증이 아니라 시간대 프로파일 수준의 정합성 점검**입니다. 전체 정합률은 74.6%이며, 과잉회피(실측상 안전한 시간대인데 회피 권고) 99건, 위험 과소평가(실측상 위험한 시간대인데 추천) 26건이 확인되었습니다.

향후 행정동 단위 사고 데이터(TAAS) 확보 시 공간 해상도를 높일 수 있습니다.

### 4-7. 공간 매칭률

주정차 허용구간 데이터의 행정동 매칭 결과, **55개 구간 중 17개(30.9%)만 매칭**되었으며 매칭된 행정동은 14개입니다. 매칭 방식은 전부 좌표가 아닌 도로명·지명 문자열 대조였습니다.

## 6. 정책 활용 방법

데이터 신뢰도는 DLFI를 대체하거나 수정하는 지표가 아니라, **정책 판단의 순서를 정하는 보조 장치**입니다.

- **① 시범사업 우선(17개 동)** — 위험도와 근거가 모두 확보된 지역. 하역공간 후보지 검토 및 시범사업 대상으로 즉시 검토 가능합니다.
- **② 현장조사 우선(4개 동)** — 위험 신호는 뚜렷하나 근거 데이터가 부족한 지역. 예산 투입 전 현장 교통량 조사를 먼저 실시해야 합니다.
- **③ 관찰 유지(51개 동)** — 현 시점 우선순위는 낮으나 정기 모니터링 대상입니다.
- **④ 보완조사(10개 동)** — DLFI가 낮게 산출됐으나 데이터 부족이 원인일 가능성이 있어, **안전하다고 단정해서는 안 되는 지역**입니다.

특히 ④ 구간의 명시는 "지수가 낮으니 문제없다"는 해석을 차단하기 위한 장치이며, 데이터 기반 행정에서 흔히 발생하는 미측정 지역의 사각지대 문제에 대응합니다.
